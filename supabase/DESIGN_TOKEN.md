# FlowVault Design Token Sheet

## 1. Spacing Scale (4/8 System)
- **4px (`gap-1` / `p-1`):** Tight inline icon & badge gaps
- **8px (`gap-2` / `p-2`):** Compact button & label spacing
- **12px (`gap-3` / `py-3`):** Brand lockups & medium button height
- **16px (`gap-4` / `p-4`):** Header padding & standard element gaps
- **24px (`gap-6` / `p-6`):** Card internal padding & grid gaps
- **32px (`space-y-8` / `p-8`):** Section container spacing
- **64px (`py-16`):** Major section vertical rhythm

## 2. Typography (2 Fonts Max)
- **UI & Headings:** Inter (`font-sans`)
- **Code, IDs & Status Badges:** JetBrains Mono (`font-mono`)
- **Type Scale:**
  - `H1`: 36px–48px (`text-4xl sm:text-5xl`), Bold, `-0.02em` tracking
  - `H2`: 24px (`text-2xl`), SemiBold
  - `H3`: 16px–18px (`text-base` / `text-lg`), SemiBold
  - `Body`: 14px–16px (`text-sm` / `text-base`), Regular
  - `Code / Meta`: 12px (`text-xs`), JetBrains Mono

## 3. Color Palette (1 Accent Color)
- **Canvas Background:** `#020617` (`bg-slate-950`)
- **Elevated Surface / Card:** `#0F172A` (`bg-slate-900`)
- **Border Subtle:** `#1E293B` (`border-slate-800`)
- **Text Primary:** `#F8FAFC` (`text-white` / `text-slate-100`)
- **Text Secondary / Muted:** `#94A3B8` (`text-slate-400`)
- **Single Accent:** `#2563EB` (`bg-blue-600` / `text-blue-500`)
